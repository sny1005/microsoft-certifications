# AB-100 Resources

## Knowledge

- [Study guide for Exam AB-100 — Microsoft Learn](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ab-100)
  The authoritative skills-measured list (updated 2026-07-22). Use for: scoping every lesson; checking domain weights (Plan 25–30%, Design 25–30%, Deploy 40–45%).
- [Learning path: Architect AI solutions for business productivity — Microsoft Learn](https://learn.microsoft.com/en-us/training/paths/architect-agentic-ai-business-solutions/)
  Official 11-module path aligned to the exam. Use for: primary reading source attached to each lesson.
- [Microsoft Copilot Studio documentation](https://learn.microsoft.com/en-us/microsoft-copilot-studio/)
  Use for: topics, actions, generative orchestration, MCP extensibility, Computer Use, agent flows.
- [Microsoft 365 Copilot extensibility documentation](https://learn.microsoft.com/en-us/microsoft-365-copilot/extensibility/overview)
  Use for: declarative agents, connectors, when to extend vs build.
- [Azure AI Foundry documentation](https://learn.microsoft.com/en-us/azure/ai-foundry/)
  Use for: Foundry Agent Service, model catalog/router, custom models. (User's strong area — reference only.)
- [Microsoft Power Platform documentation](https://learn.microsoft.com/en-us/power-platform/)
  Use for: ALM, environments, Well-Architected Framework, AI hub.
- [Cloud Adoption Framework — AI agents](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework/ai-agents/)
  Technology plan (SaaS vs custom decision tree), single-vs-multi-agent guidance, governance/operations. Use for: Plan domain lessons; the exam's favorite decision trees live here.
- [Copilot Studio architecture guidance](https://learn.microsoft.com/en-us/microsoft-copilot-studio/guidance/architecture/)
  Fit-for-purpose, operability, trust/traceability principles for agent solutions. Use for: Design domain lessons.
- [Azure AI Foundry model router concepts](https://learn.microsoft.com/en-us/azure/ai-foundry/openai/concepts/model-router)
  Use for: ROI/cost lesson — routing criteria, static/weighted/fallback rules.
- [Dynamics 365 Copilot documentation](https://learn.microsoft.com/en-us/dynamics365/copilot/)
  Per-app Copilot features (Sales, Customer Service, Finance, Supply Chain). Use for: D365 design/orchestration lessons.
- [Microsoft 365 Copilot Agent Management Essentials](https://learn.microsoft.com/en-us/copilot/microsoft-365/agent-essentials/agent-essentials-overview)
  Prereqs, blueprint, checklist, admin guide for M365 agent deployment. Use for: Deploy-domain governance lessons.
- [Copilot Studio analytics documentation](https://learn.microsoft.com/en-us/microsoft-copilot-studio/analytics-overview)
  Use for: monitoring/tuning lessons (Deploy domain).
- [Exam sandbox](https://aka.ms/examdemo)
  Use for: familiarizing with question formats before exam day.
