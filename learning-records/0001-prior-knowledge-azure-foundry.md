# Prior knowledge: Azure AI Foundry and IaaS/PaaS are strong; business-apps side is the gap

The user is a senior data scientist building AI solutions on Azure in a corporate environment. They self-report strength in Azure AI Foundry (models, code-first agents, Foundry Tools) and IaaS/PaaS infrastructure (virtual networks, Container Apps). They report weakness across the rest of the AB-100 surface: Dynamics 365 Copilot features, Copilot Studio, Power Platform, Microsoft 365 Copilot extensibility, and strategy/governance/ALM/ROI topics.

**Evidence:** self-report in first session, corroborated by job background.

**Implications:** Skip Foundry fundamentals; instead use Foundry concepts as analogies when introducing business-app concepts (e.g., Copilot Studio generative orchestration vs Foundry Agent Service). Bias lesson sequencing toward the Plan and Design domains' business-app content and the Deploy domain (40–45% of exam).
