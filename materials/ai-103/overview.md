# AI-103 Overview — Azure AI Apps and Agents Developer Associate

Fetched 2026-08-16 from Microsoft Learn credential page + study guide (aka.ms/AI103-StudyGuide).

## Credential facts
- Full name: **Microsoft Certified: Azure AI Apps and Agents Developer Associate**
- Exam: **AI-103: Developing AI Apps and Agents on Azure** — live (out of beta ~mid-2026); **replaces AI-102** (retired 2026-06-30).
- Level: Intermediate. Role: AI Engineer / Developer.
- Validates: designing, developing, deploying advanced Azure AI solutions using **Python** and **Microsoft Foundry**.
- Duration: **120 min**. Pass ≥ 700. Proctored; may include interactive components.
- Practice Assessment: available via **AI Skills Navigator** (sign-in required) — https://aiskillsnavigator.microsoft.com/credentials/cert-3fb198f57997226a824aa5f52a1a22af9a4597941b2288ed39371c7a9e6bd7c9
- Exam sandbox: https://go.microsoft.com/fwlink/?linkid=2226877
- Languages: EN, zh-CN, zh-TW, FR, DE, JA, KO, IT, pt-BR, ES.
- Renewal: annual, free online assessment on Learn.

## Audience profile (verbatim from study guide)
Azure AI engineer who builds, manages, deploys agents and AI solutions on Microsoft Foundry. Responsibilities: plan/manage Azure AI solutions; implement generative AI + agentic solutions; implement computer vision; implement text analysis; implement information extraction. Collaborates with business stakeholders, solution architects, data scientists, DevOps engineers, cloud security engineers. Requires Python app-dev experience.
