# AB-100 Study Guide (cached 2026-08-16)

Source: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ab-100
Skills measured **as of July 22, 2026**. Pass mark: **700+**.

## Skills at a glance

- Plan AI-powered business solutions (25–30%)
- Design AI-powered business solutions (25–30%)
- Deploy AI-powered business solutions (40–45%)

## Audience profile (condensed)

Accomplished solution architect designing AI-driven business solutions. Competencies: architecting with generative AI + Foundry Tools; agentic-first design; multi-agent orchestration; secure scalable cross-platform AI; core Dynamics 365, Power Platform, Copilot Studio, Foundry Tools/Models; open standards (A2A, MCP); Microsoft Responsible AI Standard; securing models/data workflows (vulnerabilities, data residency, access controls, audit trails, prompt manipulation defense); monitoring agent performance/telemetry; ROI analysis.

Key responsibilities: envision architecture strategies for AI/agents; roadmap agentic-first processes; design/prototype AI components; guide end-to-end implementation; champion adoption; ALM strategy for agentic-first solutions; environment strategy incl. third-party AI; guide orgs to become AI-forward.

## Plan AI-powered business solutions (25–30%)

### Analyze requirements
- Assess the use of agents in task automation, data analytics, and decision-making
- Review data for grounding: accuracy, relevance, timeliness, cleanliness, availability
- Organize business solution data to be available for other AI systems

### Design overall AI strategy
- Implement the AI adoption process from the Cloud Adoption Framework for Azure
- Design the strategy for building AI and agents in business solutions
- Design a multi-agent solution using Microsoft 365 Copilot, Copilot Studio, Microsoft Foundry
- Develop use cases for prebuilt agents
- Define solution rules/constraints for Copilot Studio, Foundry, Foundry Tools
- Determine use of generative AI and knowledge sources in Copilot Studio agents
- Determine when to build custom agents or extend Microsoft 365 Copilot
- Determine when custom AI models should be created
- Guidelines for creating a prompt library
- Use cases for customized small language models
- Prompt engineering guidelines and techniques
- Elements of the Microsoft AI Center of Excellence
- Design AI solutions that use multiple Dynamics 365 apps

### Evaluate costs and benefits
- Select ROI criteria incl. total cost of ownership
- Create an ROI analysis for a proposed AI solution
- Analyze whether to build, buy, or extend AI components
- Implement a model router to route requests to the most suitable model

## Design AI-powered business solutions (25–30%)

### Design AI and agents
- Business terms for Copilot in D365 customer experience/service apps
- Customizations of Copilot in D365 customer experience/service apps
- Connectors for Copilot in Dynamics 365 Sales
- Agents for Dynamics 365 Contact Center channels
- Task agents; autonomous agents; prompt and response agents
- Propose Foundry Tools for a requirement
- Code-first generative pages and agent feed for apps
- Topics for Copilot Studio, incl. fallback
- Data processing for AI models and grounding
- AI components in Power Apps canvas app business processes
- Power Platform Well-Architected Framework for intelligent app workloads
- Standard NLP vs conversational language understanding vs generative AI orchestration in Copilot Studio
- Agents and agent flows with Copilot Studio
- Prompt actions in Copilot Studio

### Design extensibility
- Custom models in Microsoft Foundry
- Agents in Microsoft 365 Copilot
- Agent extensibility in Copilot Studio
- Agent extensibility with Model Context Protocol in Copilot Studio
- Computer Use in Copilot Studio for task automation in apps/websites
- Agent behaviors in Copilot Studio: reasoning, voice mode
- Optimize with agents in Microsoft 365 (Teams, SharePoint)

### Orchestrate configuration for prebuilt agents and apps
- AI features in D365 finance and supply chain apps
- AI features in D365 customer experience and service apps
- Microsoft 365 agents for business scenarios
- Microsoft 365 Copilot for Sales and Copilot for Service configuration
- Power Platform AI features, incl. AI hub
- Interoperability of finance and operations agent chats with additional knowledge sources
- Adding knowledge sources to in-app help/guidance for D365 Finance / Supply Chain Management

## Deploy AI-powered business solutions (40–45%)

### Analyze, monitor, tune
- Process and tools for monitoring agents
- Analyze backlog and user feedback of AI/agent usage
- AI-based tools to analyze, identify issues, tune
- Monitor agent performance and metrics
- Interpret telemetry data for performance and model tuning

### Manage testing
- Process and metrics to test agents
- Validation criteria of custom AI models
- Validate Copilot prompt best practices
- End-to-end test scenarios across multiple D365 apps
- Strategy for creating test cases using Copilot

### Design the ALM process
- ALM for data used in AI models and agents
- ALM for Copilot Studio agents, connectors, actions
- ALM for Microsoft Foundry Agents service
- ALM for custom AI models
- ALM for AI in D365 finance and supply chain apps
- ALM for AI in D365 customer experience and service apps

### Responsible AI, security, governance, risk, compliance
- Design security for agents; governance for agents; model security
- Analyze solution/AI vulnerabilities and mitigations, incl. prompt manipulation
- Review adherence to responsible AI principles
- Validate data residency and movement compliance
- Access controls on grounding data and model tuning
- Audit trails for changes to models and data
