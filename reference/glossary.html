Agent anatomy (Copilot Studio)

TermDefinition
TopicUnit of conversational logic bound to an intent; built from trigger phrases, messages, questions, conditions, actions.
System topicBuilt-in topic for greeting, escalation, fallback, disambiguation, errors, end-of-conversation.
Fallback topicSystem topic that handles unmatched intent; should acknowledge, offer alternatives, optionally escalate, capture feedback.
Entity extractionPulling structured values (names, numbers, dates) from user utterances in a topic so actions receive clean inputs.
Generative orchestrationLLM-driven mode: agent selects topics/tools/knowledge by description, combines sources, auto-prompts for missing inputs.
Classic orchestrationTrigger-phrase matching mode; single topic selected; knowledge only as fallback or explicit call.
CLUAzure Conversational Language Understanding; trainable intent/entity models for varied phrasing within bounded domains.
Knowledge sourceGrounding content for generative answers: SharePoint, OneDrive, Dataverse, public sites, uploaded docs, Azure AI Search, connectors. Limits: 500 knowledge objects/agent; ≤5 unstructured sources in simultaneous retrieval.
Generative answers node"Conversational boosting" node; dynamic retrieval-based answers without authored topics; usable as fallback.
Conversational boostingThe system topic generative orchestration auto-creates; produces dynamic answers from knowledge when no topic matches.
Node-level knowledge sourceKnowledge attached to a specific generative answers node or topic; prioritized over agent-level sources when both exist.
ActionExecutable operation via connector, API, Dataverse, or flow; has inputs, output schema, auth, error handling.
Agent flowCopilot Studio-native automation (trigger + actions); no Power Automate license required; billed from Copilot message capacity.
Cloud flowPower Automate automation requiring its own license; the enterprise-integration counterpart to Copilot Studio agent flows.
Prompt actionReusable instruction block (goal, context, rules, examples, output format) an agent calls to generate/reason/transform.
Prompt CoachCopilot Studio template enforcing structured prompt sections for consistency.
Trigger (event)Event that starts an autonomous agent (Dataverse row, schedule, file upload); must be explicitly authorized; affects billing.
Computer UseCopilot Studio capability letting agents operate UIs (click, type, read screen) when no API/connector exists.
Extensibility layerOne of four Copilot Studio customization levels — instruction-level, skill/capability, integration, pro-code (VS Code) — in increasing order of power and cost.
Site contextSharePoint agent behavior: the agent automatically knows its host site, treats it as primary grounding, and adapts to its structure.
Deep reasoningCopilot Studio reasoning mode (preview) for multi-step, constraint-heavy tasks; slower and costlier than standard.
Standard reasoningCopilot Studio's default reasoning mode: fast, low-compute responses for high-volume, simple tasks; contrast deep reasoning.

Dynamics 365 customer experience

TermDefinition
Business termsStandardized org vocabulary in Dataverse fields/option sets/classification metadata that Copilot reads for summaries and recommendations; mis-mapped fields yield misinterpreted categories, outdated terminology, wrong next steps.
Structured summary formatCopilot conversation summary in predefined sections (Customer Issue, Actions Taken, Pending Items, Next Steps, Resolution Status); for documentation standards/regulated industries; contrast the narrative paragraph format.
OmnichannelD365 Customer Service/Contact Center model unifying voice, live chat, and digital messaging (SMS/WhatsApp) under one routing and agent experience.
IVRInteractive Voice Response; the telephony self-service front end a voice agent serves — demands short phrasing, confirmation steps, and interruption/backtracking tolerance.
Custom connectorPower Platform wrapper for an external API (host/base URL/security + OpenAPI definition), consumed by Power Apps, Power Automate, and Copilot Studio actions; for Copilot in D365 Sales it must be created in a Dynamics 365–enabled environment (default environment unsupported).

Interoperability & protocols

TermDefinition
MCPModel Context Protocol; standardized contract for agents to consume tools/data context. In D365 F&O exposes entities, metadata, domain models.
MCP context boundaryThe scope of business context an MCP contract exposes to an agent; aligned to compliance domains, enforced least-privilege by user identity.
A2AAgent2Agent protocol; controlled delegation and context sharing between agents.
Microsoft Agent FrameworkSDK implementing orchestration patterns: sequential, concurrent, group chat, handoff, Magentic.
Sequential orchestrationPipeline pattern: agents run in fixed order, each output feeding the next; deterministic and auditable.
Concurrent orchestrationParallel pattern: independent subtasks run simultaneously and results are aggregated.
Group chat orchestrationModerated pattern: agents propose and deliberate; a moderator selects.
Handoff orchestrationEscalation pattern: control transfers to a specialist agent or human when a threshold trips.
Magentic orchestrationDynamic pattern: an orchestrator pulls in expert agents at runtime as the problem demands.
Connected agentsFoundry pattern: main agent + specialized role agents (planner, researcher, reviewer, actuator) with scoped permissions.
Copilot client pluginsF&O extensibility: custom actions/knowledge invoked from in-app Copilot chat; backed by X++ methods.

Data & grounding

TermDefinition
GroundingSupplying trusted organizational data at inference so responses are accurate, current, auditable.
RAGRetrieval-Augmented Generation; production pipeline: ingest → clean → chunk → embed → index → retrieve → prompt assembly → monitor.
Semantic indexM365's lexical+semantic content map across Graph; continuously updated; honors permissions.
Copilot Retrieval APIRetrieves relevant passages from SharePoint/OneDrive/connectors, honoring user permissions.
Five grounding dimensionsAccuracy, relevance, timeliness, cleanliness, availability.
Hybrid searchVector + keyword + semantic ranker; the default-preferred retrieval mode for relevance.
Data pollutionDuplicates, stray metadata, and noise in grounding content; the cleanliness failure mode; degrades embeddings and retrieval precision.
Semantic rankerReranking step that re-scores retrieved passages by semantic relevance; the "semantic" leg of hybrid search.
Top-KThe fixed number of highest-scoring passages retrieval hands to prompt assembly.
Permission trimmingQuery-time filtering so retrieval returns only what the calling user may access.
Red/gold datasetsRed = mutable experimental data (dev); gold = frozen, promoted, immutable evaluation/production data.

Governance, security, operations

TermDefinition
Responsible AI principlesMicrosoft's six: Fairness, Reliability & Safety, Privacy & Security, Inclusiveness, Transparency, Accountability.
DLP policyData loss prevention rules restricting connectors/actions/data movement in Power Platform environments.
Sensitivity labelPurview classification that travels with content and constrains AI use/transmission.
Managed identitySecret-free Entra identity for agent/model/pipeline authentication; preferred over keys.
OBO (on-behalf-of)Auth pattern where the agent propagates the calling user's permissions; vs. app-identity acting as itself.
ALMApplication lifecycle management; for AI: versioned agents, prompts, models, datasets + promotion gates across Dev→Test→Prod.
GenAIOpsDeployment automation for generative AI — validations, approvals, environment-specific deploys; the GenAI counterpart to MLOps.
Managed solutionPower Platform packaging unit; only managed solutions deploy to Test/Prod.
Model cardDocumented metrics, constraints, training data refs, and usage boundaries for a model version.
Model routerFoundry unified endpoint routing requests across models by task, cost, latency; static/weighted/fallback/version rules.
Static routing ruleModel-router rule hard-mapping a request attribute to a model (task = classification → SLM; domain = finance → fine-tuned model).
Weighted routing ruleModel-router rule splitting traffic by percentage across models; used for A/B tests and gradual rollouts.
Fallback routingModel-router rule redirecting requests to a backup model when the primary fails or is unavailable.
Version-based routingModel-router rule directing traffic by model version — latest stable for production, experimental for a canary cohort.
SLMSmall language model (e.g., Phi); use for high domain specificity, latency/cost constraints, edge — not as an incorrect-information silver bullet.
HITLHuman-in-the-loop; approval checkpoints gating high-impact agent actions.
Model drift / data driftDegradation of output quality over time / shift in input data distribution; both monitored against baselines.
TCOTotal cost of ownership across five drivers: infrastructure, development/integration, data quality, expertise, operations+licensing.
Payback periodMonths for net benefit to recover the initial one-time cost: Initial_Cost ÷ Net_Monthly_Benefit.
ROI sensitivity bandOptimistic/expected/conservative ROI scenarios varying adoption, minutes saved, and labor rates; own telemetry anchors the band, field research is directional only.
Savings capabilityCopilot Studio Analytics feature recording savings per run or per tool; admins can disable money-based savings, in which case time is tracked and converted.
Agent hubD365 Contact Center/Customer Service admin hub for adopting and monitoring autonomous agents (Intent, Case Management, Knowledge Management, Quality Evaluation).
SidecarCopilot chat experience alongside a D365 app (vs. embedded in-page AI vs. outside/external agents).
CABChange Advisory Board; approval gate for high-risk AI releases.
Agent readiness criteriaPlan-phase entry gate for builds: data availability, governance readiness, identity model, connectors.
Agent governance charterReady-phase foundation artifact: capability access, data boundaries, approvals, monitoring.
Agent Ops playbookManage-phase operations handbook for production agents: SLOs, retraining rules, deprecation criteria.
Prompt libraryCurated, governed set of reusable prompts with owner/version/risk metadata; a strategic AI CoE asset.
Prompt maturity modelL1 basic → L2 guided → L3 structured → L4 optimized → L5 enterprise governed prompt library.
